I take SaaS products from empty repo to paying users. Most of my work is **Next.js + TypeScript** on the front, **Node or Laravel** on the back, with **Postgres** underneath.

I care about the parts that decide whether a product survives contact with real users: typed boundaries end to end, auth that doesn't leak, Stripe that actually reconciles, and admin dashboards a non-technical operator can run without calling me.

Recent work spans a multi-tenant salon booking platform, a restaurant POS with a real-time kitchen display, a subscription coaching app with automated onboarding, and a Swiss B2B lead engine — all four running in production today.
